# Master Projects Registry (`+Project`)

This file is the **Source of Truth** for valid projects in ChronoFlow Desktop.
The AI Agent must assign tasks **ONLY** to the projects listed below.

---

## Registered Project Buckets

### 1. `+GovExam` (Government Exam Preparation)
* **Short Syntax:** `+GovExam`
* **Scope:** All study sessions, subject syllabus chapters (Polity, History, Geography, Economy, Reasoning, Quantitative Aptitude), mock tests, revision cycles, and previous year question (PYQ) analysis.
* **Default Tags:** `#deepwork`, `#study`, `#revision`, `#practice_mock`

### 2. `+Coding` (Software & Engineering Projects)
* **Short Syntax:** `+Coding` (or `+Dev`)
* **Scope:** Full-stack development, frontend/backend feature building, bug fixing, refactoring, code review, architecture design, and open-source contributions.
* **Default Tags:** `#coding`, `#feature`, `#bug`, `#review`, `#dev`

### 3. `+Stream` (Live Streaming & Content Production)
* **Short Syntax:** `+Stream`
* **Scope:** Live stream broadcasts, pre-stream OBS / audio setup, chat interactions / intermissions, thumbnail/asset preparation, stream highlights, and post-stream backups.
* **Default Tags:** `#live`, `#prep`, `#break`, `#wrapup`, `#content`

### 4. `+Life` (Personal, Routine & Health)
* **Short Syntax:** `+Life` (or `+Personal`)
* **Scope:** Daily workout/exercise, meditation, reading, personal finances/bills, groceries, housekeeping, and sleep routine.
* **Default Tags:** `#health`, `#routine`, `#admin`, `#quick`

---

## Rules for Adding New Projects
* Do NOT create transient or micro-projects (e.g. `+BugFixToday`, `+PolityCh4`).
* High-level areas of responsibility are permanent projects; specific deliverables are tasks and subtasks inside those projects.

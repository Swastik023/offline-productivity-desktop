# Master Tags Registry (`#Tag`)

This file is the **Source of Truth** for valid tags in ChronoFlow Desktop.
The AI Agent must use **ONLY** the standardized tags defined here.

---

## 1. Cognitive Energy & Focus Tags
| Tag | When to Use | Typical Time Slot |
| :--- | :--- | :--- |
| `#deepwork` | Maximum cognitive load, memorization, complex problem-solving | Early Morning / Peak Energy |
| `#coding` | Active software development, implementing features, writing tests | Mid-Day / Afternoon |
| `#revision` | Active recall, flashcards, reviewing previous notes | Morning or Late Afternoon |
| `#practice_mock` | Timed mock test solving and answer key analysis | Morning or Mid-Day |
| `#review` | Pull request review, verifying code, proofreading text | Afternoon |
| `#admin` | Emails, scheduling, filing, low-friction organizing | Late Afternoon / Evening |
| `#quick` | Tasks under 10–15 minutes that build immediate momentum | Anytime |

---

## 2. Live Streaming Tags
| Tag | When to Use |
| :--- | :--- |
| `#live` | Core live broadcast session on stream |
| `#prep` | Setting up OBS scenes, checking audio/microphone, notifying Discord |
| `#break` | Stream intermission, stepping away, hydration, chat Q&A |
| `#wrapup` | Ending broadcast, saving recording, git push, post-stream log |

---

## 3. Habit & Health Tags
| Tag | When to Use |
| :--- | :--- |
| `#health` | Exercise, gym, walking, stretching, hydration |
| `#routine` | Morning startup routine, evening shutdown ritual |
| `#urgent` | Time-sensitive deliverables or deadlines |

---

## Strict Policy on Synonyms
* Use `#study` or `#deepwork` (never create `#studying`, `#exam_study`, `#study_time`).
* Use `#coding` (never create `#development`, `#programming`, `#code`).
* Use `#prep` (never create `#preparation`, `#setup_obs`).
